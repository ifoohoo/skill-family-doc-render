# `modern` 内置文档站模板

`modern` 是 `skill-family-doc-render` 内置的现代三栏响应式静态文档主题（旧名 `editorial` 自动映射到本模板）：

- 顶部吸顶毛玻璃导航栏：产品标题、版本胶囊、`⌘K / Ctrl+K` 全文搜索与单图标浅/深色主题切换；
- 桌面三栏黄金骨架（默认 `1400px` 外框：256px 分组目录 + 780px 居中阅读版心 + 220px 实时滚动高亮大纲；`>=1920px` 宽屏外框放宽至 `1560px`，两侧导航加宽而正文列严格维持 `780px` 最佳阅读行宽）与极简悬停浮现 `#` 标题锚点；
- 内置 6 大 AI 技能族原生组件（全站联动宿主 `Tabs`、带左侧靛蓝紫竖条与胶囊徽章的 AI 提示词卡片 vs 静态高亮代码块、序号步骤流、能力导览卡片网格、目录结构树、四色语义提示框与图表内嵌）；
- 所有静态资源保持干净磁盘文件名（`assets/theme.css`、`assets/site.js`、`assets/search-index.json`、`assets/mark.svg`），HTML 引用自动注入真实字节的 `?v=<sha256前8位>` 内容指纹防旧缓存。
